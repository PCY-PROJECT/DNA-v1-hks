WHITEPAPER

技术白皮书

DNAcloud 的核心设计原则、系统架构与支付协议。

🧬 什么是 DNA 包

DNA（Dynamic Node Agent）包是一种跨平台的 AI Agent 能力扩展标准。安装后，AI Agent 获得新的专家工作流、子代理、快捷命令和 MCP 工具集成。

  • Skills — 自然语言触发的专家工作流（Claude Code）
  • Agents — 专注特定子任务的 AI 子代理
  • Commands — /slash 快捷命令
  • MCP — 外部服务工具集成（跨平台通用标准）
  • Rules — 平台规则文件（CLAUDE.md / AGENTS.md / .cursorrules）

💰 收益结算模型

平台采用透明的分润模型，每笔购买自动入账，无需创作者手动申请提现。

  • 买家支付 → 进入平台公共账户
  • 平台收取 20% 手续费
  • 创作者获得 80% 净收益
  • 账本实时记录，金额精确到最小单位
  • 平台异步打款到创作者 EVM 收款地址
  • 支持 USDG · USDT · USDC（xlayer / Mantle）

🔐 安全审核机制

所有上传的 DNA 包经过自动化多层审核，确保买家安全。

  • ZIP 路径穿越攻击防护
  • 私钥 / 助记词 / JWT 扫描
  • 危险命令模式检测（curl|bash 等）
  • 文件类型白名单（仅 .md .json .yaml 等）
  • manifest 字段完整性校验
  • payout 收款地址格式验证

⛓️ OKX x402 支付协议

DNAcloud 基于 HTTP 402 Payment Required 协议，实现无跳转的链上原生支付体验。

  • GET artifact → 服务端返回 402 + 支付挑战
  • 客户端用 OKX API Key 签名支付凭证（HMAC-SHA256）
  • 携带凭证重试请求 → 服务端验证签名
  • 验证通过 → 结算 + 返回签名 artifact
  • 全程无需跳转钱包或外部页面

操作指引

按步骤操作，5 分钟内完成安装或发布。

🛒 买家：安装 DNA
🚀 卖家：发布 DNA
0

前置要求

确保已安装 Claude Code（claude.ai/code）和 Node.js 18+。买家需要 OKX API Key 完成支付。

# 检查环境
node --version # 需要 >= 18.0.0
1

安装 dnacloud CLI

全局安装 CLI 工具，提供 init / install / verify / status 等命令。

npm install -g @dnacloud/cli
2

在项目中初始化

在你的 Claude Code 项目根目录运行初始化，自动写入 Bootstrap Skills / Agents / Commands，并注册 DNAcloud MCP Server。

cd your-claude-project
dnacloud init
3

配置 OKX 支付凭证

在项目 .env 文件中配置 OKX API Key，用于 x402 支付签名。

OKX_API_KEY=your_api_key
OKX_SECRET_KEY=your_secret_key
OKX_PASSPHRASE=your_passphrase
⚠️ 不要把 .env 文件提交到 Git。该文件已在 .gitignore 中。
4

用自然语言安装 DNA

重启 Claude Code 后，直接在对话框中说出需求，DNAcloud Skill 自动搜索并引导购买。

# 在 Claude Code 对话框中说：
"我要一个交易大师"
"搜索 DNA marketplace"

# 或直接用 CLI：
dnacloud install trading-master-dna
5

验证安装结果

安装完成后运行验证，确认所有组件状态为 active，并查看需要配置的环境变量。

dnacloud verify trading-master-dna
dnacloud status
6

使用已安装的 DNA 能力

安装 Trading Master DNA 后，以下命令在 Claude Code 中即刻可用：

/trade-plan # 制定交易计划
/risk-check # 风险检查
/order-preview # 下单前预览
/portfolio-status # 查看持仓
/daily-trade-review # 日终复盘
⚠️ Trading Master DNA 不保证盈利。真实下单前需配置 TRADING_API_KEY 等 MCP 凭证。
0

前置要求

需要 Claude Code + Node.js 18+，以及一个 EVM 钱包地址用于接收收益（MetaMask 或任意 EIP-191 兼容钱包）。

1

安装 CLI 并初始化

npm install -g @dnacloud/cli
cd your-workspace
dnacloud init
2

创建 DNA 包结构

在 Claude Code 中运行 /dna-create，引导生成标准包目录、manifest.json、install-plan.json 和 SKILL.md 模板。

# 在 Claude Code 对话框中：
/dna-create my-expert-dna

# 生成结构：
my-expert-dna/
manifest.json
install-plan.json
skills/my-expert-dna/SKILL.md
agents/
commands/
mcp/ # 只用 ${ENV_VAR}，不写真实 key
3

填写 manifest.json

确保以下关键字段正确填写，payout.address 必须是你的收款钱包地址。

{
"id": "my-expert-dna",
"version": "1.0.0",
"objective": "install ... capabilities", // 不能承诺盈利
"price": { "amount": "0.01", "currency": "USDG", "network": "xlayer" },
"payout": { "address": "0xYourWallet...", "currency": "USDG", "network": "xlayer" }
}
4

打包并本地校验

打包前运行 validate，校验通过（score: 100）才能上传。

cd my-expert-dna
zip -r ../my-expert-dna-1.0.0.zip . -x "*.DS_Store"
cd ..
dnacloud validate my-expert-dna-1.0.0.zip
5

上传到 DNAcloud Marketplace

填写收款地址，上传 zip 包，平台自动校验结构和安全性，通过后立即发布上架，无需额外签名。

dnacloud upload my-expert-dna-1.0.0.zip \
--payout-address 0xYourWallet...

# 上传成功后包自动进入审核 → 通过后上架
6

查看收益与结算

每次有买家购买，80% 净收益自动计入你的账本，平台异步结算到收款地址。

dnacloud creator earnings 0xYourWallet...
dnacloud creator payouts 0xYourWallet...
dnacloud creator packages 0xYourWallet...
💡 平台手续费 20%，创作者净得 80%。金额以 USDG 计算，精确到 6 位小数。
