## Problem

Claude Code is powerful, but expert setup is still manual.

小白想要一个交易大师，但他不会写 Skill，不会配置 MCP，不会写 Hook，不知道怎么设置资金管理和风险规则。创作者也很难把自己的专业能力卖给 Claude Code 用户。

DNAcloud 把专家能力变成可安装、可支付、可验证、可分发的 DNA 包。

---

## What is a DNA Package?

A DNA package is not a prompt. It is an installable capability pack for Claude Code.

It may include:

- Skills
- Subagents
- Slash commands
- MCP server config
- Hooks
- Machine-readable rules
- Tests
- CLAUDE.md patch
- Manifest and signature

---

## Buyer Flow

1. Install DNAcloud Bootstrap.
2. Tell Claude Code what expert you want.
3. DNAcloud searches the marketplace.
4. Pay with OKX x402.
5. Download signed DNA package.
6. Preview installation.
7. Install into current Claude Code project.
8. Run verify.
9. Start using your expert agent.

---

## Creator Flow

1. Run `dnacloud init`.
2. Prepare your DNA package.
3. Upload through DNAcloud Skill or CLI.
4. Set price, category, description, and receiver address.
5. Platform runs simple automated review.
6. Package is signed and listed.
7. Buyers purchase through OKX x402.
8. Platform settles creator revenue asynchronously.

## Demo Package: Trading Master DNA

Trading Master DNA is the first official DNA package.

It installs a trading capability structure into Claude Code:

- Market analysis Skill
- Risk manager Agent
- Portfolio manager Agent
- Trade plan command
- Risk check command
- MCP config templates
- Pre-trade Hook
- Rules
- Conformance tests

It does not promise profit. It proves that complex expert capability can be purchased, installed, and verified.
